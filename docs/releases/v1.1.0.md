# Rigo v1.1.0 — New name, MIT license, own logo

Rigo is a local-first Markdown editor for focused writing: plain files, a browser-based interface, and no account required.

**The editor previously named TypeCraft is now Rigo.** Nothing changes for your documents: the same Markdown files in the same folders. Your recents and preferences are migrated automatically on first start.

## Why the rename, and why now

A public release needs its licensing in order. Auditing this one surfaced a blocker: the bundled typefaces came from the vendor of another text editor, whose published terms forbid exactly what this app did — *"Do not create text editors that bundle our fonts or use them as their default typefaces"*, *"Do not redistribute them with those editors"*. That is not something to ship publicly, so the fonts were replaced with the ones that vendor itself recommends for the purpose: **IBM Plex**.

The rename settles the rest: a clean identity of its own, no product names borrowed for themes or menus, and a license file that matches what the packages already claimed.

## What's new

- **Fonts: IBM Plex Mono, Sans and Serif**, bundled under the SIL Open Font License 1.1 (unmodified files, full license text shipped). EB Garamond and Lora stay, also OFL. No visual regression: the previous faces were themselves a fork of IBM Plex Mono, so the writing texture is the same lineage — and the bundled font payload drops from **425 KB to 183 KB** (WOFF2).
- **MIT license, properly filed**: `LICENSE` at the root, `THIRD-PARTY.md` with the complete texts (OFL for the fonts, MIT for marked, BSD-3 for Markdown and the Go standard library), and the same notice inside every package (`/usr/share/doc/rigo/copyright`, `/usr/share/licenses/rigo/copyright`, `NOTICE.txt` on Windows).
- **New logo, drawn from geometry**: `tools/icon` generates it — three text lines on a rounded tile, the middle one shorter, centred and accented. That is the product's idea (the line you write on stays in the middle of the screen), not borrowed artwork. Multi-resolution `.ico` and `.icns` are built from the same source; the favicon is the same shape in SVG.
- **Themes renamed** to neutral names: **Carta**, **Sepia**, **Notte**, **OLED**. Old identifiers in local storage (`ia-light`, `typora-night`, `ia-mono`, …) are migrated to the new ones on first start, so nobody loses their setup.
- **No competitor names** in the interface, the welcome screen, the shortcuts or the desktop entry: the comparison table on the welcome screen is gone and the tooltips now describe what the mode does.
- **State moves with you**: `~/.typecraft` → `~/.rigo` (recents are copied once, the instance lock, port file and browser profile are recreated), API headers are `X-Rigo-Token` and `X-Rigo-Control`, and the repository is now `massigent/rigo` (GitHub redirects the old URLs).

## Download and install

Download the package for your system in [Release assets](https://github.com/massigent/rigo/releases/tag/v1.1.0) or in the [download folder](https://github.com/massigent/rigo/tree/downloads/v1.1.0). Use `SHA256SUMS` to verify the file.

| Platform | File | Command from the download directory |
| --- | --- | --- |
| Ubuntu | `rigo_1.1.0-1_amd64.deb` | `sudo apt install ./rigo_1.1.0-1_amd64.deb` |
| Fedora | `rigo-1.1.0-1.x86_64.rpm` | `sudo dnf install ./rigo-1.1.0-1.x86_64.rpm` |
| Linux, portable | `Rigo-x86_64.AppImage` | `chmod +x Rigo-x86_64.AppImage && ./Rigo-x86_64.AppImage` |
| Windows x64 | `Rigo-1.1.0-windows-x64-setup.exe` | Run the installer; open Rigo from the Start menu |
| macOS, Apple Silicon (M-series) | `Rigo-1.1.0-macos-arm64.zip` | Extract the ZIP and drag `Rigo.app` to Applications |
| macOS, Intel | `Rigo-1.1.0-macos-amd64.zip` | Extract the ZIP and drag `Rigo.app` to Applications |

Upgrading from TypeCraft: uninstall the old package first (`sudo apt remove typecraft` / `sudo dnf remove typecraft`), install the new one, and your documents plus the recents list carry over.

Without FUSE, use `APPIMAGE_EXTRACT_AND_RUN=1 ./Rigo-x86_64.AppImage`. The Linux packages were built and smoke-tested on Linux. Full installation on Fedora and AppImage launch through FUSE were not tested on the build host.

The Windows and macOS packages were cross-built and their payloads verified on Linux, not installed or run on native systems. The Windows installer is not Authenticode-signed. The macOS app has no Developer ID signature and is not notarized. Windows SmartScreen or macOS Gatekeeper may warn or block launch.

To check one download against the manifest, run `sha256sum --ignore-missing -c SHA256SUMS` in the download directory.
