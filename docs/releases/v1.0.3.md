# TypeCraft v1.0.3 — Safer saving and Linux packages

TypeCraft is a local-first Markdown editor for focused writing: plain files, a browser-based interface, and no account required.

## What's new

- **Safer file operations:** save responses stay tied to the correct document. TypeCraft detects external edits and respects read-only files. Save As creates a copy; Rename/Move stays a separate action.
- **More reliable preview:** task checkboxes edit the matching Markdown marker. Fenced code and the outline use the same parser, and duplicate headings are distinguishable. Local Markdown links open in the editor without navigating it away.
- **Keyboard and packaging:** `Ctrl/Cmd+Shift+O` opens the outline. Linux x86_64 builds are available as an Ubuntu DEB, a Fedora RPM and a portable AppImage.

## Download and install

[Open the Linux x86_64 download folder](https://github.com/massigent/typecraft/tree/downloads/v1.0.3). Download the package for your system and, optionally, `SHA256SUMS` to verify it.

| Platform | File | Command from the download directory |
| --- | --- | --- |
| Ubuntu | `typecraft_1.0.3-1_amd64.deb` | `sudo apt install ./typecraft_1.0.3-1_amd64.deb` |
| Fedora | `typecraft-1.0.3-1.x86_64.rpm` | `sudo dnf install ./typecraft-1.0.3-1.x86_64.rpm` |
| Linux, portable | `TypeCraft-x86_64.AppImage` | `chmod +x TypeCraft-x86_64.AppImage && ./TypeCraft-x86_64.AppImage` |

Without FUSE, use `APPIMAGE_EXTRACT_AND_RUN=1 ./TypeCraft-x86_64.AppImage`. The downloads are unsigned. The packages were inspected and each binary was smoke-tested by opening a local Markdown file. Full installation on Fedora and Ubuntu and AppImage launch through FUSE were not tested.

To check one download against the manifest, run `sha256sum --ignore-missing -c SHA256SUMS` in the download directory.
