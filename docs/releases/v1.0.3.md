# TypeCraft v1.0.3 — Safer saving and desktop packages

TypeCraft is a local-first Markdown editor for focused writing: plain files, a browser-based interface, and no account required.

## What's new

- **Safer file operations:** save responses stay tied to the correct document. TypeCraft detects external edits and respects read-only files. Save As creates a copy; Rename/Move stays a separate action.
- **More reliable preview:** task checkboxes edit the matching Markdown marker. Fenced code and the outline use the same parser, and duplicate headings are distinguishable. Local Markdown links open in the editor without navigating it away.
- **Keyboard and packaging:** `Ctrl/Cmd+Shift+O` opens the outline. Packages are available for Linux x86_64, Windows x64, and macOS (Apple Silicon and Intel).

## Download and install

Download the package for your system in [Release assets](https://github.com/massigent/typecraft/releases/tag/v1.0.3) or in the [download folder](https://github.com/massigent/typecraft/tree/downloads/v1.0.3). Use `SHA256SUMS` to verify the file.

| Platform | File | Command from the download directory |
| --- | --- | --- |
| Ubuntu | `typecraft_1.0.3-1_amd64.deb` | `sudo apt install ./typecraft_1.0.3-1_amd64.deb` |
| Fedora | `typecraft-1.0.3-1.x86_64.rpm` | `sudo dnf install ./typecraft-1.0.3-1.x86_64.rpm` |
| Linux, portable | `TypeCraft-x86_64.AppImage` | `chmod +x TypeCraft-x86_64.AppImage && ./TypeCraft-x86_64.AppImage` |
| Windows x64 | `TypeCraft-1.0.3-windows-x64-setup.exe` | Run the installer; open TypeCraft from the Start menu |
| macOS, Apple Silicon (M-series) | `TypeCraft-1.0.3-macos-arm64.zip` | Extract the ZIP and drag `TypeCraft.app` to Applications |
| macOS, Intel | `TypeCraft-1.0.3-macos-amd64.zip` | Extract the ZIP and drag `TypeCraft.app` to Applications |

Without FUSE, use `APPIMAGE_EXTRACT_AND_RUN=1 ./TypeCraft-x86_64.AppImage`. The Linux binaries were smoke-tested by opening a local Markdown file. Full installation on Fedora and Ubuntu and AppImage launch through FUSE were not tested.

The Windows and macOS packages were cross-built and their payloads verified on Linux, not installed or run on native systems. The Windows installer is not Authenticode-signed. The macOS app has no Developer ID signature and is not notarized. Windows SmartScreen or macOS Gatekeeper may warn or block launch.

To check one download against the manifest, run `sha256sum --ignore-missing -c SHA256SUMS` in the download directory.
