# TypeCraft v1.0.5 — Double click selects the word

TypeCraft is a local-first Markdown editor for focused writing: plain files, a browser-based interface, and no account required.

## What's new

- **Double click selects the word again**: with typewriter scrolling enabled, every single click recentered the view (smooth scroll to bring the active line to 45% of the viewport). The text moved under the cursor between the two clicks of a word selection, so the second click landed a line above the intended word — reported against 1.0.4 as "double click selects the line above and scrolls the page".
- **How it works now**: the typewriter recentering after a mouse click is deferred by the double-click window and cancelled by any new mousedown — covering double and triple clicks of any speed, which also freeze any smooth scroll still animating from a previous recenter. A click with `detail > 1` (the second or third click of a selection) never recenters: the selection stays under the cursor. Keyboard-driven recentering (typing, arrow keys, outline jumps) is unchanged, and a plain single click still recenters, just after the short window.
- **Regression coverage**: four new jsdom tests drive the real editor and assert the deferral, the cancellation by mousedown/dblclick, and the restored single-click behaviour (150 frontend tests in total).

## Download and install

Download the package for your system in [Release assets](https://github.com/massigent/typecraft/releases/tag/v1.0.5) or in the [download folder](https://github.com/massigent/typecraft/tree/downloads/v1.0.5). Use `SHA256SUMS` to verify the file.

| Platform | File | Command from the download directory |
| --- | --- | --- |
| Ubuntu | `typecraft_1.0.5-1_amd64.deb` | `sudo apt install ./typecraft_1.0.5-1_amd64.deb` |
| Fedora | `typecraft-1.0.5-1.x86_64.rpm` | `sudo dnf install ./typecraft-1.0.5-1.x86_64.rpm` |
| Linux, portable | `TypeCraft-x86_64.AppImage` | `chmod +x TypeCraft-x86_64.AppImage && ./TypeCraft-x86_64.AppImage` |
| Windows x64 | `TypeCraft-1.0.5-windows-x64-setup.exe` | Run the installer; open TypeCraft from the Start menu |
| macOS, Apple Silicon (M-series) | `TypeCraft-1.0.5-macos-arm64.zip` | Extract the ZIP and drag `TypeCraft.app` to Applications |
| macOS, Intel | `TypeCraft-1.0.5-macos-amd64.zip` | Extract the ZIP and drag `TypeCraft.app` to Applications |

Without FUSE, use `APPIMAGE_EXTRACT_AND_RUN=1 ./TypeCraft-x86_64.AppImage`. The Linux packages were built and smoke-tested on Linux. Full installation on Fedora and AppImage launch through FUSE were not tested on the build host.

The Windows and macOS packages were cross-built and their payloads verified on Linux, not installed or run on native systems. The Windows installer is not Authenticode-signed. The macOS app has no Developer ID signature and is not notarized. Windows SmartScreen or macOS Gatekeeper may warn or block launch.

To check one download against the manifest, run `sha256sum --ignore-missing -c SHA256SUMS` in the download directory.
