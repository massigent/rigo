# TypeCraft v1.0.4 — Hardening review fixes

TypeCraft is a local-first Markdown editor for focused writing: plain files, a browser-based interface, and no account required.

## What's new

- **Safer session credentials:** the UI token no longer travels on the browser command line (readable through `/proc`). The page receives it from the `/api/init` handshake, also when the active document cannot be read at startup, and every fetch authenticates with a header instead of a query string.
- **Bounded request bodies:** save, rename and folder creation cap their JSON payloads (413 over 32 MiB), so a runaway client cannot buffer an unbounded document in memory.
- **More predictable secrets:** if the system CSPRNG is unavailable the app now fails to start instead of degrading to a predictable token.
- **Consistent defaults and metadata:** "Save as" prefers `~/Documents` on any locale (not only `Documenti`), `/api/init` reports the real OS, and `recents.json` is written atomically like a document save.
- **Windows-friendly file browser:** breadcrumbs and the workspace label split on both path separators, and a drive (`C:`) is a clickable root crumb.
- **Calmer external reloads:** when another program changes a clean document, the caret and viewport stay in place instead of jumping to the end.
- **Removed dead code:** the unused `/api/export/html` endpoint, an unreachable modal and formatting case.
- **CI on every push and pull request:** `gofmt`, `go vet`, Go unit tests and the 146 jsdom frontend tests now run before a release is cut.

## Download and install

Download the package for your system in [Release assets](https://github.com/massigent/typecraft/releases/tag/v1.0.4) or in the [download folder](https://github.com/massigent/typecraft/tree/downloads/v1.0.4). Use `SHA256SUMS` to verify the file.

| Platform | File | Command from the download directory |
| --- | --- | --- |
| Ubuntu | `typecraft_1.0.4-1_amd64.deb` | `sudo apt install ./typecraft_1.0.4-1_amd64.deb` |
| Fedora | `typecraft-1.0.4-1.x86_64.rpm` | `sudo dnf install ./typecraft-1.0.4-1.x86_64.rpm` |
| Linux, portable | `TypeCraft-x86_64.AppImage` | `chmod +x TypeCraft-x86_64.AppImage && ./TypeCraft-x86_64.AppImage` |
| Windows x64 | `TypeCraft-1.0.4-windows-x64-setup.exe` | Run the installer; open TypeCraft from the Start menu |
| macOS, Apple Silicon (M-series) | `TypeCraft-1.0.4-macos-arm64.zip` | Extract the ZIP and drag `TypeCraft.app` to Applications |
| macOS, Intel | `TypeCraft-1.0.4-macos-amd64.zip` | Extract the ZIP and drag `TypeCraft.app` to Applications |

Without FUSE, use `APPIMAGE_EXTRACT_AND_RUN=1 ./TypeCraft-x86_64.AppImage`. The Linux packages were built and smoke-tested on Linux. Full installation on Fedora and AppImage launch through FUSE were not tested on the build host.

The Windows and macOS packages were cross-built and their payloads verified on Linux, not installed or run on native systems. The Windows installer is not Authenticode-signed. The macOS app has no Developer ID signature and is not notarized. Windows SmartScreen or macOS Gatekeeper may warn or block launch.

To check one download against the manifest, run `sha256sum --ignore-missing -c SHA256SUMS` in the download directory.
